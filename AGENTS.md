# Instrucciones para trabajar en este proyecto

Antes de modificar el código o la configuración, consulta `arquitectura.md` en la raíz del repositorio para identificar los archivos implicados, las dependencias y las diferencias entre web y escritorio.

Contrasta esa referencia con el código actual: el documento es un mapa de orientación y puede quedar desactualizado. Si el cambio afecta a responsabilidades, estructura, contratos, persistencia o disponibilidad por plataforma, actualiza también las secciones y entradas correspondientes de `arquitectura.md`.

Al cambiar funciones compartidas, revisa su implementación web y de escritorio, incluido el auxiliar Python cuando intervenga.
